# 🌕 Luna AI Research Center - Об'єднана Платформа ## Загальна функціональність системи ### Огляд системи Luna AI Research Center - це об'єднана веб-платформа для наукового моделювання умов Місяця. Система складається з чотирьох основних модулів: Energy, Radiation, Thermo та Artemis 2 Lab. Платформа побудована на Node.js з Express.js, використовує PostgreSQL для зберігання даних та має сучасний frontend з Tailwind CSS та Chart.js. ### Архітектура системи - **Backend**: Node.js + Express.js - **База даних**: PostgreSQL з Pool підключенням - **Frontend**: HTML/CSS/JavaScript з Tailwind CSS - **Візуалізація**: Chart.js для графіків - **Стиль**: Glassmorphism дизайн з зірковим фоном ### Основні модулі #### 1. LunaEnergy AI (Енергетичний модуль) **Функціонал:** - Розрахунок ефективності сонячних панелей на Місяці - Врахування кута нахилу, інтенсивності сонця, температури, пилового фактора - Порівняння ефективності Земля vs Місяць - Вплив пилу на панелі з рекомендаціями чистки - ROI калькулятор для місячних станцій - Збереження експериментів у БД - Статистика: загальна кількість, середні значення, мінімум/максимум - Експорт даних у CSV **API Endpoints:** - POST /api/energy/calculate - розрахунок ефективності - GET /api/energy/experiments - отримання експериментів - GET /api/energy/stats - статистика - POST /api/energy/clear - очищення даних - POST /api/energy/compare - порівняння Земля/Місяць - POST /api/energy/dust-impact - вплив пилу - POST /api/energy/roi - ROI аналіз #### 2. LunaRadiation AI (Радіаційний модуль) **Функціонал:** - Моделювання захисту від космічної радіації - Розрахунок проникнення радіації через матеріали - Підтримка матеріалів: Алюміній, Вода, Реголіт - Багаторівневий захист (новий функціонал) - Оцінка дози для астронавтів - Оптимальний матеріал для захисту - Збереження експериментів - Статистика та візуалізація **API Endpoints:** - POST /api/radiation/calculate - розрахунок проникнення - GET /api/radiation/experiments - експерименти - POST /api/radiation/multi-layer - багаторівневий захист - POST /api/radiation/astronaut-dose - доза для астронавтів - POST /api/radiation/optimal-material - оптимальний матеріал #### 3. LunaThermo AI (Термодинамічний модуль) **Функціонал:** - Моделювання теплопередачі на Місяці - Розрахунок втрат тепла через матеріали - Аналіз місячного циклу день/ніч - Тепловий баланс системи - Підтримка різних матеріалів та товщин - Рекомендації для ізоляції - Збереження та аналіз експериментів **API Endpoints:** - POST /api/thermo/calculate - розрахунок теплопередачі - GET /api/thermo/experiments - експерименти - POST /api/thermo/lunar-cycle - місячний цикл - POST /api/thermo/thermal-balance - тепловий баланс #### 4. Artemis 2 Lab (Модуль місії Artemis II) **Функціонал:** - Розрахунок delta-v бюджету для місії - Оцінка радіаційної експозиції в Deep Space - Логування сценаріїв місій - Журнал Artemis з візуалізацією - Інтерактивні форми для розрахунків - Збереження місій у БД - Ризик-аналіз та рекомендації **API Endpoints:** - POST /api/artemis/compute-dv - розрахунок delta-v - POST /api/artemis/compute-exposure - радіаційна експозиція - POST /api/artemis/log-mission - збереження місії - GET /api/artemis/experiments - отримання місій ### Загальні функції платформи #### Дані та зберігання - PostgreSQL база даних з ініціалізацією таблиць - Автоматичне створення таблиць при запуску - Pool підключення для ефективності - Збереження всіх експериментів та місій #### Інтерфейс користувача - Responsive дизайн для всіх пристроїв - Glassmorphism стиль з анімаціями - Зірковий фон з плавною анімацією - Інтерактивні форми з валідацією - Візуалізація даних через графіки Chart.js #### Експорт та аналітика - CSV експорт для всіх модулів - Статистичні звіти - Порівняльний аналіз - ROI розрахунки #### Безпека та продуктивність - CORS підтримка - Валідація вхідних даних - Помилка обробки - Оптимізація запитів до БД ### Запуск системи 1. Встановити залежності: `npm install` 2. Налаштувати .env файл з DATABASE_URL 3. Запустити сервер: `npm start` 4. Відкрити http://localhost:3000 ### Структура файлів ``` /Luna-AI-Unified/ ├── server.js # Головний сервер Express ├── db.js # Ініціалізація БД ├── package.json # Залежності ├── public/ │ ├── index.html # Головна сторінка │ ├── energy/ # Модуль енергії │ ├── radiation/ # Модуль радіації │ ├── thermo/ # Модуль термодинаміки │ └── artemis/ # Модуль Artemis └── README.md # Документація ``` ### Розвиток та покращення - Додавання нових модулів - Інтеграція з реальними даними місій - Розширена візуалізація - API для зовнішніх інтеграцій - Мобільний додаток Система розроблена для наукових досліджень умов Місяця та підготовки до майбутніх місій Artemis. c:\Users\Admin\Documents\GitHub\Luna AI Research Center\Luna-AI-Unified\SYSTEM_FUNCTIONALITY.txt
